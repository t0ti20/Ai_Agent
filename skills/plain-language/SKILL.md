# Plain language

1. Find the one point the reader must take away and lead with it.
2. Replace jargon with everyday words. If a technical term must stay, define it
   in a few words the first time it appears.
3. Use short sentences (under about 20 words) and the active voice.
4. Prefer concrete examples over abstractions.
5. Cut anything that does not help the reader act or understand.

This is a project-level skill: every agent in this repo can load it. Put skills
that only one agent needs in that agent's own `skills/` folder.
